# wm2 참조형 인식 모델 시범판 (10k 스텝, 2026-11-23)

**중간 산출물이다.** 20k 스텝 일정의 10k 시점 체크포인트이고, 같은 학습이 계속 돌고 있다(끝나면 갱신본을 올린다).

## 무엇을 하는 모델인가 (이전 "한 장 단독 인식"과 다름)
- **입력 2개**: ① 워터마크가 박혔을 수 있는 이미지 ② **예시 마크 하나**(테스트툰 맨 첫 장에서 잘라 낸 것, 흰 또는 검은 배경).
- **출력**: 그 예시 마크가 이미지 어디에 박혀 있는지(확률 지도 → 상자). 예시 마크가 여러 개면 예시마다 한 번씩 돌린다.
- 위치·크기가 매번 달라도, 반투명(알파 낮음)이어도, 한 이미지에 같은 마크가 여러 개여도 찾도록 학습·평가했다. 예시와 다른 글자(말풍선 등)는 걸러지도록 "다른 마크만 있는 조각" "같은 종류의 다른 마크"를 학습에 넣었다.
- 화면의 20%를 넘는 상자는 버린다(화면 전체를 워터마크로 잡는 것 방지). 20%는 **상자 면적 ÷ 화면 면적**으로 해석했다.

## 직접 써 보기
```
pip install onnxruntime numpy pillow scipy
python infer_ref.py wm2_ref_unet_10k_20261123.onnx sample/ref_core_001/gallery.png sample/ref_core_001/img_01.jpg sample/ref_core_001/img_02.jpg --out out
```
- `out/갤러리_분리.png`: 첫 장에서 분리된 예시 마크(번호 #0, #1…). `out/<이미지>_det.png`: 찾은 상자와 예시 번호·점수. 터미널에 상자 좌표도 출력.
- **본인 이미지**로 쓰려면: 첫 장에 예시 마크들을 흰/검은 배경 위에 **서로 충분히 띄워서** 놓고(가로 띠마다 배경이 달라도 됨, 가장 왼쪽 열 색을 배경으로 봄), 이어서 워터마크가 박힌 이미지를 넣는다. 예시 마크는 **이미지에 박힌 것과 비슷한 크기**로 두는 것이 좋다(학습은 크기 0.7~1.3배 범위).

## ONNX 규격
- 입력 `image` float32 `[1,3,h,w]`: RGB 0~1, 원본을 **0.5배 BOX 축소**한 뒤 아래·오른쪽을 reflect 패딩해 **h,w를 16의 배수**로(동적 축).
- 입력 `ref` float32 `[1,3,112,192]`: 예시 마크를 0.5배 BOX 축소해 **배경색으로 채운 112×192 캔버스 가운데**에 놓은 것(큰 마크는 캔버스에 맞춰 더 줄임).
- 출력 `logits` `[1,1,h,w]` → sigmoid. 임계값 0.5 → 6픽셀 팽창·덩어리·30픽셀 미만 제거 → 상자(좌표 ×2). PyTorch↔ORT 로짓 차이 0.00016. 이 PC ORT CPU 약 136ms/쿼리(800×368 입력).

## 결과 (합성 테스트툰, 임계값 0.5)
테스트툰 = 맨 첫 장(예시 마크 1~5개) + 뒤 이미지 4~8장. 정답 = 이미지별 (예시 번호, 상자). 상자 IoU≥0.5이고 예시 번호가 같아야 맞음.

| | core(120세트·741장) | val(40세트·239장, 학습에 없는 글꼴) |
|---|---|---|
| 상자 재현율 | 81.4% | 72.9% |
| 상자 정밀도 | 43.3% | 39.4% |
| 이미지에 없는 예시를 있다고 함(이미지×예시 쌍) | 24.4% | 18.0% |
| 마크가 하나도 없는 이미지에서 상자를 냄 | 12.1% | 24.6% |
| 이미지에 있는 예시를 찾아냄(이미지×예시 쌍) | 90.8% | 87.6% |
| 갤러리 자동 분리 성공 | 100% | 100% |

종류별 상자 재현율(core / val): badge 88/91, emblem 87/82, icon 86/87, qr 94/100, **text 72/68, url 75/56, outline 67/37**. 크기가 예시의 0.85배 미만이면 72/61%, 알파 0.4 이상(진한 마크)에서도 76/69%로 약하다. 글자 위주 마크(text·url·outline)가 약점이다.

## 한계·주의 (솔직하게)
- **중간 체크포인트(10k/20k)** — 학습률이 아직 높은 시점이라 끝난 모델보다 낮다. 갱신본이 나오면 교체한다.
- **정밀도 43%**: 상자의 절반 이상이 엉뚱한 곳이다. 앱에서는 "같은 예시가 여러 장에서 비슷하게 나오는지" 확인하는 후처리가 필요하다.
- **합성 이미지로만 검증**했다. 실제 웹툰·실제 사이트 워터마크로는 시험하지 않았다. 폰 CPU 시간도 측정하지 않았다.
- 예시 마크 크기가 이미지에 박힌 것과 2배 이상 다르면 약하다(크기 범위 밖은 학습하지 않음). 전면 반복 무늬는 대상이 아니다(20% 상한).
- 갤러리 분리는 "배경과 확연히 다르고 서로 떨어진 마크" 가정이다. 한 마크가 여러 덩어리로 갈라지거나 마크끼리 붙어 있으면 실패할 수 있다(합성 벤치에서는 100%).
