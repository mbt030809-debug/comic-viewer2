# wm2 인식 파이프라인 시험판 (2026-11-24, 갱신) — 예시 마크를 단색 여백에서 찾고, 그림 위에서 찾기

**기본 설정은 신경망 없이 규칙 + SIFT 특징점 매칭만 쓴다(빠름, 앱 이식이 가장 쉬움).** 합성 테스트툰으로만 평가했고 실제 웹툰은 검증하지 않았다.
사양: `wm2/RECOGNITION_SPEC_20261123.md`. 방식 비교 기록: `wm2/COMPARE_ABC_20261123.md`.

## 한눈에
입력 = 같은 사이트 이미지 3~8장(순서·위치 모름). 그중 한 장의 **단색(흰/검은) 여백**에 **예시 워터마크**가 있고, 다른 이미지의 **그림 위**에 같은 마크가 박혀 있다(불투명 중심·반투명 포함, 위치·크기·약간의 회전이 매번 다름, 한 이미지에 여러 개/없음).
출력 = 어느 예시가 어느 이미지의 어디에 있는지 (예시 번호 + 상자).

```
1단계(규칙 v5): 모든 이미지에서 '단색 여백 안의 마크 후보'(예시 후보) 찾기
2단계(SIFT):   후보마다 모든 이미지에서 특징점 매칭 + RANSAC 닮음변환으로 위치·크기 구하기 (인라이어 ≥ 6)
확인:          후보가 자기 페이지 밖 이미지에서 발견될 때만 채택(캡션·쪽번호 후보 제거), 예시와 크기·가로세로비(0.6~1.75배)가 다른 상자·면적 20% 초과 상자 제외
```

## 파일
| 파일 | 내용 |
|---|---|
| `pipeline_ref.py` | **기준 구현**. 기본 = 규칙 + SIFT(`pip install numpy pillow scipy opencv-python-headless`). 신경망 옵션(`--s1 hybrid/neural`, `--s2 nn`, `--consensus`, `--also-kp`)은 onnxruntime 추가 |
| `s1_rule.py` | 1단계 규칙 v5(단색 여백 + 크기·모양 규칙) |
| `s2_kp.py` | 2단계 SIFT + RANSAC (OpenCV `SIFT_create`, `estimateAffinePartial2D`) |
| `wm2_s1_unet_10k_20261124.onnx` | (선택) 1단계 신경망. 입력 `image` [1,3,h,w](0.5배 BOX 축소 + 16배수 reflect 패딩, RGB 0~1) → `logits` [1,1,h,w] |
| `wm2_ref_unet_25k_20261124.onnx` | (선택) 2단계 참조형 신경망. 입력 `image`(위와 같음) + `ref` [1,3,112,192](예시, 0.5배 축소, 배경색 캔버스) → `logits` |
| `sample/ref3_core_0xx/` | 시험용 합성 세트 3개(이미지 + `truth.json` 일부 + `expected_out/result.json` = 기본 설정의 출력). 폰 이식 후 같은 입력으로 비교 |

## 돌려 보기 (PC)
```
pip install numpy pillow scipy opencv-python-headless
python pipeline_ref.py sample/ref3_core_002 --out out
```
`out/result.json` 에 `examples`(1단계가 찾은 예시)와 `detections`(이미지·예시 번호·상자·점수), `out/*_det.png` 에 그림이 저장된다.

## 성능 (합성 테스트툰, 재현율 / 정밀도 / 마크 없는 이미지 오검출 %)
정밀도 = 표시한 상자 중 진짜 비율, 재현율 = 박힌 마크 중 찾은 비율, 마지막 항목 = 마크가 하나도 없는 이미지에서 상자를 낸 비율(말풍선·머리·눈 오검출의 척도).

| 설정 | core(120세트) | val(40세트, 학습에 없는 글꼴) | 완전 새 벤치(60세트) |
|---|---|---|---|
| **기본: 규칙 + SIFT(인라이어 6)** | 42.6 / 71.4 / 3.8 | 45.4 / 72.2 / 2.6 | 38.7 / 69.6 / 5.5 |
| 규칙 + SIFT(인라이어 8) | 39.4 / 75.6 / 3.5 | 40.5 / 75.6 / 1.3 | 34.8 / 74.2 / 3.1 |
| 규칙 + 신경망 합의 + SIFT | 43.8 / 72.4 / 3.8 | 45.6 / 75.7 / 2.6 | 40.3 / 71.5 / 5.5 |
| 규칙+신경망(hybrid) 1단계 + 합의 + SIFT (정밀 우선) | 28.6 / 81.5 / 1.2 | 26.9 / 76.1 / 1.3 | 28.2 / 86.8 / 0.0 |
| 규칙 1단계 + 신경망 ∪ SIFT (재현 우선) | 66.2 / 22.8 / 69.2 | 71.3 / 25.5 / 69.2 | 67.9 / 26.1 / 68.5 |
| 학습형 1단계 + 신경망 ∪ SIFT | 50.4 / 31.0 / 46.5 | 43.1 / 33.8 / 37.2 | 47.4 / 30.7 / 40.2 |
- 신경망을 더해도 기본(규칙 + SIFT)보다 재현율이 1%p 안팎만 오른다 → **신경망 없이도 충분**. 신경망은 속도·이식 비용만 늘린다.
- 처리 시간: core 120세트(이미지 703장, 예시 후보 673개) 전체 평가가 약 136초(PC CPU, 신경망 없음). 폰 CPU 시간은 측정하지 않았다.
- 비교한 다른 방식(템플릿 매칭만 18%/9%, 신경망만 42%/28% 등)과 XFeat(CVPR 2024, SIFT보다 낮음)는 `wm2/COMPARE_ABC_20261123.md` 참조.

## 후처리 규칙(모두 `pipeline_ref.py` 에 있음)
- 2단계 상자는 예시와 폭·높이가 0.6~1.75배 안, 면적 ≤ 화면의 20%, 예시가 있던 자리 자체는 제외.
- 크기 사양(이미지 폭 대비): 로고류 8~30%, 글자류 10~50%. 1단계 규칙이 이 범위로 후보를 거른다.

## 한계 (솔직하게)
- **합성 이미지로만 평가**. 새 벤치도 같은 생성기에서 시드·글꼴만 바꾼 것이다. 실제 웹툰은 검증하지 않았다(사용자 요청으로 실제 이미지는 쓰지 않음).
- 1단계 규칙이 캡션·쪽번호 같은 글줄도 후보로 만든다(예시의 91~95% 찾지만 정밀도 40~47%). 2단계의 반복 확인이 이를 걸러 낸다.
- SIFT는 특징점이 적은 마크(얇은 글자·외곽선 글자·반투명 마크)에서 약하다. 종류별 재현율: 배지·QR·캐릭터가 높고 글자·URL·외곽선 글자가 낮다.
- 예시 크기가 그림 위 마크와 2배 이상 다르면 약하다(합성은 0.75~1.33배로 만듦).
- 폰 CPU 시간 미측정. SIFT·RANSAC은 OpenCV(Android 포함)에 있어 이식이 쉽지만, 1단계 규칙(팽창·라벨링·구멍 메우기)은 직접 옮겨야 한다.
