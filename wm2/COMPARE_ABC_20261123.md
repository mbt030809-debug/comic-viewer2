# wm2 인식 a/b/c 비교 (2026-11-23, 합성 테스트툰만)

정의(사용자 지정 이름): **a 신경망 기반**, **b 규칙 기반**, **c 규칙+신경망 기반**.
파이프라인: 1단계 = 사이트 이미지 중 어느 한 장(위치 모름)의 단색(흰/검은) 여백에서 예시 워터마크 찾기, 2단계 = 그 예시를 나머지 이미지의 그림 위(불투명 60% + 반투명 40%)에서 찾기, 마지막에 반복 확인(후보가 다른 이미지 1장 이상에서 발견될 때만 채택).

| | 1단계 | 2단계 |
|---|---|---|
| a | U-Net 학습형(0.95M, 10k 스텝, `train_s1.py`) | 참조형 신경망(0.99M, `train_ref.py --synth v3`, 10k 스텝 이어 학습) |
| b | 규칙 v5(`s1_rule.py`) | 템플릿 매칭(다중 크기 정규화 상관, `s2_tm.py`, 문턱 0.65) |
| c | 규칙 v5가 후보 → 신경망 마스크가 상자의 25% 이상을 '예시'로 볼 때만 채택 | a와 같은 참조형 신경망 |

테스트툰: `gen_refbench3.py`(core 120세트·703장, val 40세트·239장(학습에 없는 글꼴), 완전 새 벤치 60세트·343장(새 시드, val 글꼴)). 정답 = 이미지별 (예시 번호, 상자), 맞음 = 번호 같고 IoU≥0.5. 2단계 상자는 예시 크기의 0.6~1.75배·가로세로비 범위 안인 것만 인정(머리카락·눈 조각 제외).

## 해석
- 1단계: 규칙은 재현율이 높고(91~95%) 캡션을 많이 잡는다(오검출 401개 중 237개). 신경망은 캡션을 거의 안 잡지만(16개) 마크를 놓친다. 규칙+신경망은 정밀도 80% 이상이지만 재현율 약 50%.
- 종단: a가 재현율 최고, c가 정밀도 최고, b는 둘 다 최저(템플릿 매칭이 글자·외곽선·도장에 약함).
- 말풍선·머리·눈: 정답 없는 곳의 2단계 오검출이 대부분(오라클 기준 885개 중 788개)이었고, 예시 크기 일치 필터로 정밀도가 21% → 45%로 올랐다.
- **불투명 마크가 약하다**(오라클 2단계 재현율 50%, 반투명 79%). 응답 자체가 없는 경우(p<0.3)가 불투명의 42%. 비율·스타일·코덱·종류에 고르게 퍼져 있어 학습 부족으로 보인다(`diag_s2.py`). 2단계를 25k 스텝으로 더 학습 중.

## 한계
합성 이미지로만 평가. 새 벤치도 같은 생성기에서 시드·글꼴만 바꾼 것이라 완전히 다른 만화는 아니다. 실제 웹툰은 검증하지 않았다. 1단계 학습형은 학습 분포(합성 여백 띠)와 벤치의 격차로 재현율이 낮다.

## 최종 갱신 (2단계 25k 스텝, 템플릿 매칭 보강, 규칙 1단계 + 신경망 2단계) — 재현율 / 정밀도 / 마크 없는 이미지 오검출 %
| 방식 | core | val | 완전 새 벤치 |
|---|---|---|---|

| a + 템플릿 매칭 보강 | 46.8 / 27.3 / 51.2 | 40.0 / 32.0 / 37.2 | 43.3 / 20.0 / 42.5 |
| b 규칙 (규칙 1단계 + 템플릿 매칭) | 18.2 / 9.1 / 30.8 | 22.8 / 18.8 / 26.9 | 17.7 / 8.2 / 40.2 |
| c 규칙+신경망 (규칙 후보를 신경망이 확인 + 신경망 2단계) | 35.4 / 35.1 / 29.6 | 33.8 / 40.7 / 24.4 | 32.6 / 39.1 / 24.4 |

| c' 규칙 1단계 + 신경망 2단계 (재현율 우선, 확인 1장) | 52.6 / 19.6 / 68.5 | 53.8 / 21.1 / 66.7 | 54.1 / 23.1 / 67.7 |

- 균형(재현율·정밀도)이 가장 좋은 것은 c + 템플릿 매칭(core F1 약 37), 재현율이 가장 높은 것은 c'(52~54%, 대신 오검출이 많음).
- 오라클 1단계(정답 예시를 그대로 줌)에서 2단계는 신경망만 64%, 템플릿 매칭 보강 73%(core 30세트). 종단에서 낮은 이유는 1단계가 예시를 55~65%(학습형) 또는 91~95%(규칙, 대신 캡션이 섞임)만 맞게 주기 때문.
- 2단계를 10k → 25k 스텝으로 늘려도 개선이 거의 없었다(오라클 62% → 64%). 병목은 학습량이 아니다.
