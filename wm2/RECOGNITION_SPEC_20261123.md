# wm2 인식 사양 (사용자 확정, 2026-11-23)

사용자가 직접 확인·결정한 내용이다. 학습·벤치·앱 연결은 이 사양을 따른다. (근거 이미지는 실제 웹툰 스크린샷 2장이며 **저장소에 올리지 않았고 학습·평가에도 쓰지 않는다.**)

## 1. 과제 정의
- 테스트 한 세트 = **맨 첫 장(예시 마크들)** + 뒤 이미지들. 첫 장에는 다양한 예시 마크가 **흰 또는 검은 배경** 위에 있고, 그 마크들이 뒤 이미지에 박힌 마크 **전부**다.
- 뒤 이미지: 마크의 위치·크기가 매번 다르고, 반투명(알파 낮음), 한 이미지에 여러 개, 일부 이미지에는 없음.
- 출력: **어느 예시 마크가 어디에 있는지**(예시 번호 + 위치 상자). 둘 다 맞아야 합격.
- 실제 입력에는 뷰어 UI(`auto` 글자, 스크롤바, 화살표)가 **없다**(스크린샷에만 있음). 무시한다.

## 2. 워터마크 모양 분류 (사용자 확인: "다 맞음, 캐릭터일 수 있음")
1. 글자(영문·한글·URL)
2. 로고 + 글자 도장(원형, 마스코트 포함)
3. 심볼 + 글자 배지
4. 외곽선 글자
5. 아이콘 · QR
6. **캐릭터(마스코트)** — 단독이거나 로고에 포함. (눈·머리카락 같은 만화 요소와 헷갈리기 쉬우므로 가장 어려운 부류)

특징: 반투명 오버레이(마크 안에서 배경이 비침), 거의 단색, 깔끔한 벡터 가장자리, 장면 구조(컷 경계·말풍선 선)를 무시하고 위에 얹힘. 같은 사이트의 모든 장에 같은 모양, 위치는 x 고정·y 변동 같은 유형이 많고 한 이미지에 서로 다른 마크가 여러 개.

## 3. 크기 (이미지 폭 대비, 사용자 확정)
- **로고류**(도장·배지·아이콘·캐릭터·QR): 폭 **8~30%**
- **글자류**(글자·URL·외곽선 글자): 폭 **10~50%**
- 공통 상한: 상자 면적 **≤ 화면 면적의 20%**(화면 전체를 워터마크로 잡는 것 방지). 이 상한을 넘는 상자는 버린다.
- 사용자 메모: 로고와 글자는 크기 기준이 달라야 한다.

## 4. 알려진 오인식 (실제 웹툰, 사용자 제공 스크린샷 기준)
집중선(방사형 가는 선 다발), 머리카락·털 가닥, 눈의 광원·하이라이트, 불꽃·연기 효과(반투명 겹침). 합성 벤치에서는 같은 이미지의 다른 마크, 망점·빗금·컷 테두리·말풍선 글자·평면 색 영역.
원인 가설(미검증): 학습 배경이 합성(단색·노이즈·망점)뿐이라 실제 만화의 선화를 본 적이 없고, 모델이 "예시와 같은가"보다 "가늘고 대비 높은 구조"를 배웠을 가능성.

## 5. 개선 순서
1. 마크 합성에 캐릭터 종류 추가, 크기를 위 범위로 제한.
2. 학습·벤치 배경에 만화 선화 요소(집중선, 머리카락 가닥, 눈 하이라이트, 불꽃)를 "정답 아님"으로 추가.
3. 실제 웹툰으로의 점검은 사용자가 별도로 제공·허락할 때만(현재는 사용 금지).
